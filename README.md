🔭 I’m currently working on some open source projects:
- [ToolDB](https://github.com/Manwe-777/tool-db): A decentralized database and data sharing for peer to peer applications running mainly on the browser, without central servers!
- [MTG Arena Tool](https://github.com/mtgatool/mtgatool-desktop): A desktop overlay and companion app for Magic the Gathering: Arena, able to run seamlessly in the browser; "MTG Arena Tool is a collection browser, a deck tracker and a statistics manager for MTG Arena."
- [PID Tuna](https://github.com/Manwe-777/pid-tuna): A blackbox logs analyzer for tuning quadcopters (drones) based on the popular (but now paid software), pidtoolbox, made for the modern web; faster and easier to user, cross platform, mobile friendly. 
- [Rulebook](https://github.com/Manwe-777/rulebook): An open, decentralized, Warhammer40k rules/datasheet viewer and list builder with automatic validation and sharing, based on ToolDb/Nostr
- [EDH Hub](https://github.com/Manwe-777/edh-hub): A beautiful, smooth & lightweight life counter for EDH that works on Android natively or iOS/anything via PWA/web.
- [Toolnet](https://github.com/Manwe-777/toolnet): A private mesh VPN powered by ToolDb; no limits tailscale-like, self hosted, 100% yours.
